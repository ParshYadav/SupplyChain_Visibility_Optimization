# Supply Chain Visibility & Optimization -- Milestone 3

## Project Overview

This milestone focuses on evaluating supplier performance and
transportation efficiency using interactive Power BI dashboards. The
report enables data-driven decision-making through supplier scorecards,
KPI tracking, benchmarking, and logistics performance analysis.


# Supplier Performance Dashboard

## Objective

Evaluate supplier quality, reliability, fulfillment performance, and
overall contribution using KPI-driven scorecards.

## Supplier Scorecard Calculation Methodology

The supplier scorecard is derived using key operational KPIs: - Average
Quality Score - Average Reliability (%) - Average Lead Time (Days) -
Purchase Order Fulfillment Performance - Composite Supplier Score based
on weighted KPIs

Typical weighted approach: - Quality Score -- 40% - Reliability -- 30% -
Lead Time -- 20% - Fulfillment Performance -- 10%

Suppliers with higher quality and reliability, shorter lead times, and
better fulfillment receive higher composite scores.

## Supplier Ranking & Benchmarking Approach

Suppliers are ranked using the Composite Supplier Score.

Benchmark categories: - High Performing Suppliers - Medium Performing
Suppliers - Improvement Required Suppliers

Performance comparison includes: - Composite Score - Lead Time -
Reliability - Quality - Tier Classification

## Dashboard Features

-   Supplier Scorecards
-   Composite Supplier Ranking
-   Quality & Reliability Analysis
-   Lead Time Distribution
-   Supplier Tier Classification
-   Interactive Supplier Filters

## Key Business Insights

-   Identify top-performing suppliers.
-   Detect suppliers with high lead times.
-   Improve procurement decisions using KPI rankings.
-   Reduce supply chain risk through reliability analysis.

# Transportation Analytics Dashboard

## Objective

Analyze transportation cost efficiency, shipping performance, and
logistics operations.

## Transportation Cost Analysis Methodology

Transportation KPIs include: - Total Transportation Cost - Average
Profit per Order - Average Discount Rate - Cost per Shipment - Shipping
Mode Performance - Logistics Expense Analysis

Analysis compares transportation costs across different shipping modes
and markets.

## Route & Carrier Performance Evaluation

Performance evaluation includes: - Shipping Mode Comparison - Route
Performance - Late Shipment Rate - Order Distribution - Market-wise
Transportation Performance

KPIs are used to identify efficient shipping routes and cost-effective
transportation methods.

## Dashboard Features

-   Transportation Cost KPIs
-   Shipping Mode Analysis
-   Route Performance Heatmap
-   Late Shipment Analysis
-   Market-wise Logistics Performance
-   Interactive Date & Market Filters

## Key Business Recommendations

-   Prioritize suppliers with consistently high composite scores.
-   Improve supplier relationships to reduce lead time variability.
-   Optimize shipping modes based on cost and delivery performance.
-   Reduce transportation expenses through route optimization.
-   Monitor late shipment trends to improve service levels.
-   Use KPI dashboards for continuous supplier and logistics performance
    monitoring.
